## 3. Проблемы, которые встречались (и как решали)
- **Слетала блокировка виджетов после переключения вкладок**: блокировка жила только в
   `select.callback`, который не вызывается при десериализации (LiteGraph `configure()`
   ставит `.value` напрямую и сбрасывает `disabled`). Решение — `onConfigure`-хук,
   который заново применяет `updateWidgetState` по актуальному `select`.
- **`setWidgetDisabled` не работал для ComboWidget** (`aspect_ratio`) в ComfyUI v0.27+:
   `disabled` там read-only и читается из `w.options.disabled`. Решение — писать в
   `w.options.disabled` с fallback в try/catch.
- **`const { app } = window.comfyAPI?.app;`** падал `TypeError` при отсутствии `comfyAPI`
   (деконструкция `undefined`). Решение — фолбэк `?? window.app ?? {}`.

## 4. Что важно не сломать при продолжении работы
- Блокировка активного пресета держится на двух хуках: callback (смена select вручную)
   + `onConfigure` (десериализация). Не убирать `onConfigure` при правках JS.
- Позиции сепараторов `GROUP_START=[1,4,6,8]` соответствуют порядку `INPUT_TYPES`
   (`select, aspect_ratio, megapixels, multiple, w1, h1, w2, h2, w3, h3`). Вставка — в обратном порядке.
- `onNodeCreated` НЕ вызывается повторно при переключении вкладок (нода лишь `configure()`-ится),
   поэтому сепараторы не дублируются и высота не накапливается.
- Все правки вносить в исходник `F:\AI_projects\Custom_node_ComfyUI\Degg_Res_Set\`,
   затем `python sync.py Degg_Res_Set` в рабочую копию (`D:\ComfyUI_windows_portable\ComfyUI\custom_nodes\Degg_Res_Set\`).
